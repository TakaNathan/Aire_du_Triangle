# Aire du Triangle

Ce projet permet de calculer l'aire d'un triangle.

## Description
Le programme prend les dimensions nécessaires et retourne la superficie du triangle selon la formule :

A = (base x hauteur) / 2

## Utilisation
1. Ouvrez le projet dans votre environnement de développement.
2. Exécutez le programme.
3. Entrez la base et la hauteur du triangle.
4. Le résultat affichera l'aire calculée.

## Objectif
Ce projet est un exemple simple pour apprendre les bases du calcul et du développement.
